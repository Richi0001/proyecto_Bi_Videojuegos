**Fecha:** 15/09/2026

---

## Descripción del proyecto

Este proyecto analiza los factores que influyen en el éxito comercial de los videojuegos (género, plataforma, región y año de lanzamiento) para orientar decisiones de inversión en nuevos lanzamientos.

**Pregunta de negocio:**
¿Qué combinaciones de género, plataforma y región generan mayores ventas globales, para orientar la decisión de en qué tipo de videojuego invertir el próximo año?
